## 畫面怎麼排

- 像視覺小說：**插圖填滿整個螢幕**，旁白和對話放在下方的半透明對話框，有人說話時左上角會出現名牌。
- 開始聊天時，手機從右邊滑進來，插圖右邊稍微變暗，對話框往左讓出位置。對話框沒有字時會自動淡出。
- 手機的樣子：奶油色外框、深藍瀏海、淺色標題列（返回、名稱、電話、選單）、暖色桌布、白色和淺藍綠的泡泡，下緣超出畫面一點，像拿在手上。打字時輸入框左邊的按鈕會收起來，麥克風變成送出。顏色都在 `style.css` 最上面「手機」那一段；想用自己的桌布圖，把 `--wallpaper` 改成 `url("img/wallpaper.jpg") center / cover`。
- 選項：手機開著時出現在手機下方；手機收起來時出現在畫面中間。
- 所有尺寸都用 `--u` 當單位，1u ≈ 螢幕高度的 1%，所以不管螢幕多大，比例都一樣。想調整字的大小，改 `style.css` 最上面的 `--fs-...`。
- 對話框想改成參考圖那種白色：把 `--glass` 改成 `#f4f1ecdd`、`--glass-ink` 改成 `#2b2620`。
- **手機直著拿**：會蓋上黑底的「請將手機橫放」畫面，轉成橫的就消失。
- **手機橫放**：字有設最小值，不會小到看不清楚；手機畫面也會加寬。iPhone 的 Safari 不支援全螢幕，網址列會留著，這是 Apple 的限制。

## 操作方式

| 動作 | 電腦 | 手機 |
| --- | --- | --- |
| 繼續 | 點滑鼠、空白鍵、Enter | 點畫面 |
| 選擇 | 點選項，或按 `1`、`2` | 點選項 |
| 收回訊息 | 點一下發亮的訊息（或按住），再點「收回」；也可以連按兩次空白鍵 | 按住發亮的訊息，再點「收回」 |
| 結局卡 | 點按鈕，或按 `1`、`2`、`3` | 點按鈕 |
| 全螢幕 | `F`，或右上角按鈕；`Esc` 離開 | 橫放後按「開始」（iPhone 不支援） |

旁白和當面說的話會一個字一個字出來。打字時點一下（或按空白鍵），整句直接出來；字全部出來後要等 0.5 秒，再點一下才會繼續，所以連點兩下也不會直接跳過一句。速度在 `story.js` 的 `textSpeed` 調整（每個字隔幾毫秒，預設 50；寫 0 就整句直接出現）。

手機主人（平常是「你」）傳出的訊息，會先在手機下方的輸入框一個字一個字打出來，再送出。打字時點一下可以直接打完。

## 加新的一幕

打開 `story.js`，最上面有每一種寫法的說明。最常用的是：

```js
"2B-3": {
  lines: [
    { type: "msg", from: "阿哲", text: "沒事" },
    { type: "narr", text: "你看著那兩個字。「沒事」通常不是沒事。" },
  ],
  next: "E1-1",
},
```

然後記得把上一幕的 `next`（或選項的 `next`）改成這一幕。
沒有 `next`、沒有選項、也不是結局的那一幕，播完會顯示「待續」。

## 手機上的時間

手機狀態列左上角會顯示時間。兩種寫法：

```js
// 1. 一幕開始時設定
"1-2": {
  chat: "第三組報告群組（5）",
  clock: "22:47",
  lines: [ ... ],
},

// 2. 播到一半改時間，表現時間一分一秒過去
{ type: "clock", text: "22:58" },
```

## 依選擇顯示不同內容

選項裡的 `set` 會記住讀者選了什麼，例如 `set: { choice1: "A" }`。
之後任何一行加上 `when`，就只會在條件符合時出現：

```js
{ type: "narr", text: "是群組。", when: { choice1: "A" } },
{ type: "narr", text: "是你的私訊。", when: { choice1: "B" } },
```

隱藏章節的 `Z-3`、`Z-4` 就用這個做：讀者第一次選了 A 還是 B，阿哲那一晚看到的就不一樣。
`PROLOGUE_DM` 裡也有一個例子：你在序幕回了文字還是貼圖，之後打開私訊時就顯示哪一個。

**依選擇接到不同的幕**：`next` 寫成清單，從上面開始找，接到第一個 `when` 符合的那一幕。`when` 裡寫好幾項，就要每一項都符合；沒寫 `when` 的那一項放最後，代表其他情況。隱藏章節的 `Z-5` 就是這樣分開真結局和原本的結尾：

```js
next: [
  { when: { choice1: "B", choice2: "一起扛下" }, next: "T-1" }, // B 路線＋一起扛下：真結局
  { next: "Z-6" },                                            // 其他選擇：原本的天亮和結尾
],
```

## 這一版新增的寫法

完整說明在 `story.js` 最上面，這裡是重點：

- **已讀**：`{ type: "read", text: "已讀 2" }` 讓你最後一則訊息旁邊出現（或更新）已讀，下面會帶著送出的時間。寫在舊訊息裡就用 `read: "已讀"`；舊訊息想顯示時間，再加 `time: "22:52"`。
- **收回訊息**：`{ type: "unsend", text: "真的，每次都這樣。", hint: "…", pick: "…" }`。那則訊息會發亮，讀者要自己按住它、再按「收回」。收回後泡泡變成「你已收回訊息」，但「已讀」會留著。
- **打了又刪掉**：`{ type: "draft", text: "我外婆住院了。" }` 在輸入框打字但不送出；`{ type: "erase" }` 一個字一個字刪掉。寫在黑幕、白幕後面時不打字，字直接出現在輸入框（結局二最後，阿哲輸入框裡沒送出的那句）。
- **照片**：`{ type: "photo", from: "阿哲", id: "I03" }`，用的是 `images` 清單裡的插圖。
- **揉完眼睛、重新對焦**：`{ type: "image", id: "I02", refocus: true }`。插圖先模糊，再對焦兩次變清楚，上一句旁白會先收掉。動畫播完才接下一行，這段時間點畫面、按空白鍵都跳不過。想調速度或模糊程度，改 `style.css` 的 `refocus`。
- **螢幕暗下去**：`{ type: "dim" }`（結局一、二、四用）。
- **通知**：手機收起來時，`notify` 會改出現在畫面右上角（隱藏章節裡阿哲把手機放下的那一段）。
- **換成阿哲的手機**：在一幕裡寫 `me: "阿哲"`，之後阿哲的訊息就靠右、在輸入框打字，你的訊息靠左。換回來寫 `me: "你"`。
- **轉場小字**：`{ type: "card", text: "隱藏章節", sub: "阿哲的那一晚" }`。
- **結局**：一幕寫 `ending: "E1"`，播完就顯示結局卡。結局卡上的字寫在 `endings` 清單裡：`name`、`title` 是「結局一」「一起上台」，`tagline` 是標題下面那句話，`results` 是三行結果（冒號前面是誰），`quote` 是最後那句話（後面三個都可以不寫）。
- **再選一次**：在 `endings` 裡加 `retry: { label: "回到那一晚，再選一次", next: "2A-R" }`，結局卡上就多一個按鈕，按下去帶著這次的選擇回到 `next` 那一幕。要回到某個選項，最好像 `2A-R`、`2B-R` 那樣，先寫一幕在黑幕後面把聊天室準備好，再接到選項那一幕。
- **隱藏章節**：`secret: { start: "Z-1", title: "阿哲的那一晚", unlock: 1 }`。`unlock` 寫結局清單，看過其中任何一個就解鎖；寫數字，就是看過幾個結局就解鎖（`1` 是看過任何一個，`4` 是四個都要看過）。解鎖後結局卡和開始畫面都會出現「阿哲的那一晚」按鈕。看過哪些結局會存在瀏覽器裡，關掉再開也記得。
- **停一下**：`{ type: "pause", ms: 2500 }`。對話框先收起來，等 2.5 秒再接下一行（點一下可以不等）。用在劇本裡的（停頓），還有結局最後「停留 2～3 秒」。
- **輸入框閃游標**：`{ type: "caret" }`。輸入框裡出現閃動的游標；輸入框空著時不顯示「輸入訊息」，只剩游標在閃（結局二最後、結局四最後一晚）；輸入框有字時，游標閃在字的後面。下一次打開聊天室時消失。
- **已經收回的訊息**：history 裡的訊息加 `unsent: true`，一打開聊天室就顯示成「你已收回訊息」，已讀還留著（2A-4、結局三最後阿哲的手機）。
- **頭像**：`people` 清單裡設定每個人圓圈裡的字和顏色。之後有頭像圖片，加上 `img: "img/avatar-azhe.jpg"` 就會換成圖片。
- **重複的舊訊息**：序幕的私訊（`PROLOGUE_DM`）和第一幕的群組（`GROUP_NIGHT`）會在好幾幕當作舊訊息出現，所以寫在 `story.js` 最上面一次，用 `...PROLOGUE_DM` 放進 `history`。改了 P-2 或 1-2、1-3，記得一起改這兩個。
- `history` 只在**剛打開聊天室**時顯示；從上一幕接過來、聊天室沒換的話，不會重複出現。
- **捲到某一則**：一幕寫 `focus: "已讀 4"`，打開聊天室後會把那一則捲到中間（Z-7 用來讓手機橫放時也看得到「已讀 4」）。

## 背景音樂

1. 音檔放進 `audio` 資料夾，檔名用編號：`audio/night.mp3`。檔名大小寫要完全一樣。
2. 在 `story.js` 的 `music` 清單加一行：`night: { volume: 0.8, note: "深夜的房間：很輕的鋼琴" },`。`volume` 是這首平常的音量（0～1），`note` 是給自己看的說明。
3. 在劇情裡像呼叫函式一樣使用：

```js
"1-1": {
  chat: null,
  bgm: "night",                 // 這一幕開始時播放（寫 null 就停止）
  lines: [
    { type: "narr", text: "晚上十點四十七分。" },
    bgm("rain", { fade: 3000 }), // 播到一半換歌：舊的淡出、新的淡入，花 3 秒
    stopBgm(),                   // 停止
  ],
},
```

| 寫法 | 意思 |
| --- | --- |
| `bgm("night")` | 播放，會一直重複 |
| `bgm("night", { volume: 0.5 })` | 音量 0～1，不寫就用 `music` 清單裡的音量。正在放的同一首再寫一次，只會調音量，不會從頭放；只寫 `bgm("night")` 就回到清單裡的音量 |
| `bgm("night", { fade: 3000 })` | 淡入淡出幾毫秒，預設 1500；寫 `0` 就直接切換 |
| `bgm("ending", { loop: false })` | 只放一次 |
| `stopBgm()`、`stopBgm({ fade: 4000 })` | 停止 |
| `bgm("rain", { when: { choice1: "A" } })` | 只有選了 A 才換這首 |

- `bgm(...)` 這一行不用等，音樂一邊淡入，下一行就會開始。
- 重新開始、從結局卡「從頭再玩」、開發者面板跳場景時，正在放的音樂會淡出。
- 切到別的分頁時音樂會暫停，回來再接著放。
- 瀏覽器規定網頁要等讀者點過畫面才能出聲。按「開始」就算點過，所以正常玩不會有問題；用 `#dev` 直接跳場景時，音樂會等你點一下畫面才開始。
- **iPhone、iPad**：Apple 不讓網頁調音量，所以 `volume` 和淡入淡出在那裡沒有作用，音樂會用最大聲直接開始、直接停止。想讓某首小聲一點，直接把音檔本身調小聲最保險。
- 開發者模式（`#dev`）下找不到音檔時，畫面上方會出現紅框。
- 每首建議壓成 128kbps 的 mp3，大約 1～3MB，打開才不會慢。

## 環境音

環境音和背景音樂走不同的聲道，兩個可以同時放，例如 `calm` 的鋼琴配上深夜房間的聲音。

1. 音檔一樣放在 `audio` 資料夾，例如 `audio/home_night.mp3`。
2. 在 `story.js` 的 `ambience` 清單加一行，`volume` 是它平常的音量：`home_night: { volume: 0.5, note: "房間・晚上" },`。
3. 寫法和背景音樂一樣，只是把 `bgm` 換成 `amb`：

```js
"E1-1": {
  amb: "home_night",              // 這一幕開始時播放（寫 null 就停止）
  lines: [
    stopAmb(),                    // 換地點：寫在 fadeOut() 前面，聲音和畫面一起淡出
    fadeOut(),
    { type: "image", id: "I05" },
    amb("classroom_noisy"),       // 寫在 fadeIn() 前面，聲音和畫面一起淡入
    fadeIn(),
  ],
},
```

- `volume`、`fade`、`loop`、`when` 的用法和 `bgm(...)` 一樣。沒寫 `volume` 的話，就用 `ambience` 清單裡的音量。
- 出現結局卡時，環境音會自己淡出，背景音樂不會。重新開始、跳場景時，兩個都會淡出。
- 醫院還沒有環境音，暫時用 `home_night`。等放好 `audio/hospital.mp3`，在 `ambience` 清單加上 `hospital`，再把 `story.js` 上面的 `HOSPITAL_AMB` 改成 `"hospital"`。
- 清單裡的音量是我量過每個音檔的大小聲之後定的。`classroom_noisy` 本身很大聲，和 `calm` 的鋼琴差不多，所以只開到 0.2。**iPhone、iPad 不能調音量**，每個環境音都會用音檔本來的音量播，`classroom_noisy` 會和音樂一樣大聲。想在手機上也聽起來正常，最好直接把音檔本身調小聲。
- 開發者模式（`#dev`）下找不到音檔時，畫面上方會出現紅框。

## 收到訊息的提示音

別人傳來的訊息、貼圖、照片，還有通知出現時，會響一聲 `audio/received.mp3`。

- 設定在 `story.js` 的 `messageSound: { id: "received", volume: 0.6 }`。`volume` 是音量；不要提示音就改成 `messageSound: null`。
- 手機主人自己傳的訊息、`history` 裡的舊訊息不會響。隱藏章節換成阿哲的手機時，換成阿哲收到的訊息會響。
- 某一則不想響，就在那一行加上 `sound: false`：

```js
{ type: "msg", from: "阿哲", text: "第四部分我會弄完。", sound: false },
```

  2A-2 的這一則就是這樣寫的：2A-1 跳出通知時已經響過一次，打開私訊時就不再響。
- 想換別的聲音，把音檔放進 `audio` 資料夾，再把 `id` 改成它的檔名（不用寫 `.mp3`）。
- iPhone、iPad 不能調音量，提示音會用音檔本來的音量播。

## 黑幕、白幕和地點字條

```js
lines: [
  { type: "narr", text: "那天晚上，我一直沒睡。" },
  fadeOut(),                                     // 慢慢變黑，停在黑幕
  { type: "narr", text: "……" },                 // 黑幕上也可以放旁白
  { type: "image", id: "I14" },                  // 在幕後面換插圖
  fadeIn(),                                      // 慢慢露出畫面
  place("市立醫院　病房", { sub: "凌晨 2:10" }),  // 左上角的地點字條
  { type: "narr", text: "外婆睡著了。" },
],
```

| 寫法 | 意思 |
| --- | --- |
| `fadeOut()` | 慢慢變黑，停在黑幕 |
| `fadeOut("white")` | 慢慢變白，停在白幕 |
| `fadeIn()` | 從黑幕（或白幕）慢慢露出畫面；前面沒有幕的話，從黑幕淡入 |
| `fadeIn("white")` | 前面沒有幕時，從白幕淡入（例如回憶、醒來） |
| `fadeOut("black", { ms: 2000 })` | 淡入淡出幾毫秒，預設 1000；`fadeIn` 也一樣 |
| `fadeOut("black", { ms: 0 })` | 直接變黑，不淡出（例如轉場大字前先停在黑幕） |
| `place("市立醫院")` | 黑底白字的地點字條，從左上角淡入，停 3 秒再自己淡出 |
| `place("市立醫院", { sub: "晚上 11:40", ms: 4000 })` | 下面加一行小字；停 4 秒 |

- `fadeOut`、`fadeIn` 會等動畫播完才接下一行，這段時間點畫面也跳不過。
- 幕只蓋住插圖和手機：旁白、選項、地點字條都會出現在幕上面，所以黑幕上可以放旁白，讀者不會卡在看不到字的畫面。
- `fadeOut` 開始時，上一句旁白和地點字條會跟著淡出。
- `place` 出現 0.7 秒後就接下一行（點一下可以更快），字條自己停一下再淡出。
- 停在黑幕、白幕時重新開始或用開發者面板跳場景，幕會馬上拿掉。
- **一幕的第一行寫 `fadeOut()`**：上一幕的畫面會先淡出，才換這一幕的 `chat`、`image`。接在選項後面的那一幕最好用，因為選項那一幕沒辦法在最後寫 `fadeOut()`（結局一的 E1-1、每個結局最後換成阿哲手機的那一幕都是這樣）。
- **一幕的第一行寫 `fadeIn()`**：會先直接變黑，`chat`、`image` 在幕後面換好再淡入，不會先閃過新的畫面。
- `fadeIn` 會等幕後面換的插圖載好才淡入，最多等 3 秒（放上網路後圖片載入比較慢）。
- 停在幕後面換聊天室時，手機會直接收起或出現，不會滑動。

## 運鏡

讓插圖像攝影機一樣動。寫法和 `fadeOut()` 一樣，直接放進 `lines`：

```js
lines: [
  shake(1),                          // 輕輕一震：插圖和手機一起震
  { type: "narr", text: "手機震了一下。" },
  zoomIn(1.3, { x: 30, y: 40 }),     // 慢慢推近，把左邊那張臉移到畫面正中間
  { type: "talk", from: "阿哲", text: "我怕我講不好。" },
  zoomOut({ ms: 5000 }),             // 花 5 秒拉遠，讓情緒冷下來
],
```

| 寫法 | 什麼時候用 |
| --- | --- |
| `shake(1)`、`shake(2)`、`shake(3)` | 震動：撞到東西、驚嚇、衝擊、生氣。數字越大震得越大、越久，情緒越激烈（不寫是 2） |
| `zoomIn()`、`zoomIn(1.4, { x: 30, y: 40 })` | 慢慢推近（不寫是 1.2 倍）：走進角色的內心、這句話很重要、角色正在下決心 |
| `zoomOut()` | 慢慢拉遠回到整張圖：讓情緒冷下來、顯得孤單、看清整個場景 |
| `pan("right")`、`pan("left")`、`pan("up")`、`pan("down")` | 平移：介紹新場景、跟著角色的視線、表示時間在流逝 |

每一個後面都可以再加這些設定：

| 設定 | 意思 |
| --- | --- |
| `ms: 6000` | 花幾毫秒。沒寫的話：推近、拉遠 3000，平移 4000，震動 400～700。寫 `0` 就直接切過去 |
| `wait: true` | 等鏡頭動完才接下一行（點一下可以不等） |
| `wait: 1300` | 只等 1.3 秒就接下一行，鏡頭繼續慢慢停下來 |
| `ease: "soft"` | 前段就移得差不多，最後很長一段慢慢停穩，適合移到人身上。不寫是前後對稱的加速減速（`style.css` 的 `ease-in-out`）；也可以寫 `"linear"`（等速） |
| `when: { choice1: "A" }` | 只有選了 A 才動 |

**鏡頭移到人身上時不要太生硬**（序幕 P-1 就是這樣寫的）：慢一點（3 秒左右）、用 `ease: "soft"`、`wait` 寫數字。鏡頭快停的時候台詞就出來，鏡頭在台詞出字時才停穩，不會「移、停、說」一格一格的：

```js
zoomIn(2, { x: 57, y: 51, ms: 3000, ease: "soft", wait: 1300 }),
{ type: "talk", from: "雨晴", text: "報告分四部分，誰要哪一塊？" },
```

- 這幾行都不用等：鏡頭一邊動，下一行就開始。所以寫在一句話**前面**，就會一邊出字一邊推近。
- 推近、拉遠、平移只動插圖，手機和對話框不動。震動是插圖和手機一起震，對話框不動，字才看得清楚。
- `x`、`y` 是要移到畫面正中間的那一點：`x` 從圖的左邊 0 到右邊 100，`y` 從上面 0 到下面 100。用眼睛估就好，臉在圖的左邊三分之一、上面四分之一，就寫 `x: 33, y: 25`。不寫就沿用上一次對準的地方。
- 那一點太靠近圖的邊時，只能盡量靠近中間，不會露出圖的邊緣。放得越大，越移得到中間。
- 已經推近時再寫一次 `zoomIn`，鏡頭會從現在的位置移到新的那一點，例如從一個人的臉移到另一個人（序幕 P-1 就是這樣做的）。
- 換插圖時，鏡頭會回到整張圖。
- **從特寫拉遠、從最左邊移到最右邊**：先用 `ms: 0` 直接切到起點，再慢慢動。直接切的那一行要寫在 `fadeIn()` 前面（還停在黑幕時），讀者才不會看到畫面跳一下。結局四的空桌子就是這樣寫的：

  ```js
  fadeOut(),
  { type: "image", id: "I12" },
  zoomIn(1.4, { x: 52, y: 45, ms: 0 }),  // 在黑幕後面先切到空桌子的特寫
  zoomOut({ ms: 5000 }),                 // 一邊淡入一邊慢慢拉遠
  fadeIn(),
  ```

  平移也一樣：`pan("left", { ms: 0 })` 先切到最左邊，再 `pan("right", { ms: 15000 })`（隱藏章節 Z-6）。
  沒有黑幕、直接換插圖時，改在 image 那一行寫：`{ type: "image", id: "I13", zoom: 1.4, x: 50, y: 30 }`，新的插圖一出來就是特寫。
- 平移要先放大才有地方移：鏡頭在整張圖時，`pan` 會一邊放大到 1.25 倍一邊移過去。想移得更遠，寫 `pan("right", { zoom: 1.4 })`。
- 推近會把插圖放大，超過 1.5 倍就看得出有點糊。想推很近的那張圖，可以畫大一點（例如 2560×1440）。
- 系統開了「減少動態效果」時，不會震動；推近、拉遠、平移會直接切到最後的畫面。
- 開發者模式（`#dev`）下，寫了 `zoomOut()` 但鏡頭本來就在整張圖、沒有地方可以拉遠時，畫面上方會出現紅框提醒。
